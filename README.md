# CNCSS

Симулятор траектории ЧПУ и удаления материала на **.NET 8**, **WPF** и **Helix Toolkit (Wpf)**. Интерфейс оператора оформлен в духе панели стойки FANUC: список программы, MDI, режимы, смещения G54–G59, конструктор заготовки, воксельная симуляция съёма, библиотека инструментов, 3D-модель станка.

> **Для ИИ-агентов (Cursor и др.):** см. [`AGENTS.md`](AGENTS.md) — архитектура, инварианты заготовки/вокселей, ключевые файлы, типичные ошибки при правках.

---

## Сборка и запуск

```powershell
dotnet restore
dotnet build -c Release
dotnet run -c Release --project CNCSS.csproj
```

Минимальная проверка перед изменениями:

```powershell
dotnet test -c Release
```

| Требование | Значение |
|------------|----------|
| Платформа | Windows (`net8.0-windows`, x64) |
| SDK | .NET 8 или новее |
| Образцы УП | `O0001.nc`, `O1204.nc` копируются в выходной каталог при сборке |
| Smoke-сценарий | `DEVELOPMENT.md` |
| ИИ-агент | `AGENTS.md` |

### Особенность проекта (WinForms)

Для диалога выбора цвета инструмента и заготовки включён `UseWindowsForms`; глобальные `using` для `System.Windows.Forms` и `System.Drawing` **отключены** в `CNCSS.csproj` (`Using Remove`), чтобы не конфликтовать с типами WPF (`Color`, `Application`, …).

## Основные возможности

| Область | Описание |
|--------|----------|
| **G-код** | Разбор файла, список строк, переход к строке с корректным `MachineState`, дуги, модальные G/M. |
| **3D** | Сборка станка (STL/STEP), траектория, инструмент, заготовка (параметрическая + воксельная при обработке). |
| **Кинематика** | Профили с подвижным столом (XY) и шпинделем (Z); заготовка, контур и маркер WCS могут быть привязаны к `table.Root`. |
| **WCS / OFFSET** | G54–G59 в MCS, маркер нуля на столе (белая полупрозрачная сфера + оси), установка нуля с заготовки. |
| **Симуляция** | Пуск/удержание цикла, скорость, single block, optional stop, сухой прогон; воспроизведение с прогрессивным контуром. |
| **Заготовка** | Конструктор параметрической заготовки; невоксельная модель на столе; воксели — при Cycle Start. |
| **Станок** | Редактор профиля, импорт STEP, TCP, точка крепления детали, HOME, MCS; пользовательский заводской снимок. |
| **Инструменты** | Диалог «TOOL DATA»: тип, T, геометрия, цвет, превью. |

## Заготовка: конструктор и воксели

Параметры заготовки задаются **только через конструктор** — меню **Симуляция → Заготовка → Конструктор заготовки…** (`UI/Dialogs/StockConstructorWindow.xaml`).

### Конструктор заготовки

| Параметр | Описание |
|----------|----------|
| **Тип проката** | Прямоугольный, шестигранный, круглый, трубный. |
| **Размеры** | Зависят от типа (длина/ширина/толщина, размер под ключ + толщина, диаметр, внешний/внутренний диаметр и т.д.). |
| **Положение** | Центр заготовки по X/Y в MCS. |
| **Разрешение L2** | Шаг воксельной сетки (0.10–1.0 мм). |
| **Материал и цвет** | Список материалов, палитра из 4 базовых цветов + «Другой цвет…». |
| **Предпросмотр** | 3D-модель на столе из активного профиля станка. |

После **Подтвердить**:

- в сцене появляется **невоксельная** модель выбранной формы и цвета;
- заготовка **крепится к столу** (`SyncStockVisualToTable`, плоскость крепления из профиля);
- включается отображение заготовки (`FilterShowStock`).

### Воксельная модель

- Воксели **не** создаются при открытии конструктора или загрузке УП.
- Воксельная заготовка **всегда** строится при **Cycle Start** (пуск симуляции).
- Во время расчёта — **модальное окно** «Расчет воксельной модели…» до готовности сетки.
- При старте **цельная модель заменяется** воксельной (отображается `_stock.MainModel`).
- Форма вокселей соответствует типу из конструктора (шестигранник, круг, труба), не только bbox.
- Цвет поверхности вокселей совпадает с цветом из конструктора.

Автоматический подбор габаритов заготовки по контуру УП **отключён**.

### Видимость в сцене

| Элемент UI (`MainWindow.xaml`) | Назначение |
|--------------------------------|------------|
| `FilterShowStock` | Показать/скрыть заготовку в 3D (не влияет на расчёт вокселей). |
| `FilterShowMachine` | Скрыть/показать узлы станка; заготовка независима. |
| `FilterShowToolpath` / `FilterShowTool` | Траектория и инструмент. |

Ключевые файлы: `UI/ViewModels/StockConstructorViewModel.cs`, `Vis/StockConstructorPreviewBuilder.cs`, `Vis/StockSimulationCoordinator.cs`, `MainWindow.xaml.cs` (`ApplyStockConstructor`, `EnsureVoxelStockForRun`, `SetStockDisplayVisible`).

## Профиль станка и заводские настройки

Профили хранятся в каталоге пользователя:

- **Профили:** `%USERPROFILE%\Documents\CNCSS\Machines\<id>\` — `machine.json` и STL узлов (база, стол, шпиндель, доп. узлы).
- **Активный профиль:** `...\Machines\active.txt`.
- **Заводской снимок (задаётся пользователем):** `%USERPROFILE%\Documents\CNCSS\FactoryMachine\`.

Меню **Станок**:

| Пункт | Действие |
|-------|----------|
| Настройка модели станка… | Редактор геометрии, осей, TCP, WCS-превью, сохранение профиля. |
| Выбрать профиль станка… | Переключение между сохранёнными профилями. |
| Сохранить текущие настройки как заводские | Копирует активный профиль в `FactoryMachine`. |
| Сбросить заводской профиль | Восстанавливает `default` из снимка; если снимка нет — из STEP в `Assets\Default_Maschine.stp` или из шаблона. |

При первом запуске, если профилей ещё нет, может выполняться импорт сборки по умолчанию из STEP (см. `Machine/Configuration/MachineProfileBootstrap.cs`).

## Координаты и визуализация

- **MCS** — машинная система; смещения G54–G59 задаются в MCS (панель OFFSET / быстрая установка).
- **Программные координаты** — относительно активного WCS; физическая поза: программа + WCS + `MachineZeroOffset`.
- **Стол (table-mounted):** заготовка, траектория и маркер WCS — дочерние элементы `table.Root`; при джоге стола они движутся вместе с ним. Ноль WCS фиксируется в table-local (`WorkpieceMountPlacement`, кэш `RegisterWcsOriginTableLocal`).
- **Инструмент** — на узле крепления шпинделя; при воспроизведении контур может дополняться «шапкой» до текущей позы.

Подробности — в XML-комментариях к `Machine/Model/WorkpieceMountPlacement.cs`, `Vis/ToolpathBuilder.cs`, `Vis/MachineVisualCoordinator.cs`.

## Структура решения

| Проект / папка | Назначение |
|----------------|------------|
| **CNCSS** (корень) | WPF-приложение, `MainWindow`, композиция. |
| **Data** | `MachineState`, парсер, `GCodeRegistry`, инструменты `Tools/*`. |
| **Logic** | `GCodeParser`, `CommandReplayer`, `ProgramLoader`, каталог УП. |
| **Machine** | `Machine.Core` — кинематика VMC 3 оси; `Machine.Model` — определение станка, узлы, WCS; `Machine.Configuration` — профили, импорт STEP/STL. |
| **Controller** | `ControllerCore` — режимы, jog, MDI, цикл. |
| **Simulation** | `Simulation.Bus` — события; `Simulation.Execution` — исполнение УП, интерполяция, playback. |
| **Vis** | `ToolpathBuilder`, `MachineVisualCoordinator`, `VoxelStock`, `WcsMarkerVisualBuilder`, `StockConstructorPreviewBuilder`, импорт мешей. |
| **UI** | Стойка FANUC, презентеры, ViewModels, диалоги станка, инструментов и конструктора заготовки. |
| **Geometry** | BRep, swept volume (экспериментально). |
| **Infrastructure** | `AppCompositionRoot` — сборка зависимостей. |
| **CNCSS.Tests** | xUnit: парсер, кинематика, профили, toolpath, WCS. |

Поток данных: **парсер → команды и состояния → траектория и блоки движения → шина событий ↔ контроллер/станок → MainWindow обновляет Helix и панели.**

## Воксельная заготовка (движок)

- Заготовка делится на **чанки** (`Data/Tools/VoxelChunk.cs`), компактное хранение битами.
- Начальная занятость задаётся **маской формы** из конструктора (`StockSimulationCoordinator.BuildOccupancyMask`).
- Удаление материала учитывает траекторию и радиус инструмента (`VoxelStock`).
- Визуализация: пересчёт изменённых чанков, greedy meshing по внешней поверхности.

Разрешение сетки задаётся в конструкторе заготовки (разрешение L2). `VoxelSimulationProfile` задаёт профиль качества; `VoxelPerformanceMonitor` пишет в debug output длительность пересборки меша.

## Разбор G-кода

- Реестр кодов и модальность — `GCodeRegistry`, `GCodeTemplate`.
- Парсер поддерживает типичные адреса X/Y/Z, F/S/T, плоскости и дуги с I/J/K или R.
- `ParsedCommand` связывает строку файла с параметрами и состоянием станка (перемотка и симуляция).
